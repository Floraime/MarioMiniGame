# 1 Gato Curioso

## Description
This project consists of the development of a mini game created in Unity as part of an academic activity.
The game includes a main menu, scene transitions, a basic 3D environment, character integration, animations, a timer system, audio elements, and a dynamic obstacle that interacts with the player.

## Features
- Main menu with Start button
- Scene transition from menu to gameplay
- Basic 3D environment with lighting and objects
- Functional timer system
- Character integration with visual adjustments
- Basic animations (Idle state)
- Dynamic obstacle with vertical movement
- Collision detection using Rigidbody and Colliders
- Audio integration for enhanced user experience

## How to Play
1. Open the project in Unity.
2. Run the main scene from the editor.
3. Click the **Start** button in the main menu.
4. Move the character within the environment.
5. Avoid the moving obstacle.
